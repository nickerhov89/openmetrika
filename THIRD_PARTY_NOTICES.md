# Third-party notices

OpenMetrika is MIT-licensed. Dependencies retain their original copyrights/licenses.
The package lock records exact versions. Dependencies are installed from npm,
not copied from Yandex services.

Primary runtime dependencies:

- React / React DOM — MIT, Meta and contributors.
- Express — MIT, Express contributors.
- rrweb / rrweb-player and rrweb-snapshot — MIT, rrweb contributors.
  https://github.com/rrweb-io/rrweb
- Lucide icons — ISC, Lucide contributors. https://lucide.dev/

The tracker build preserves extracted license comments. npm packages include their
full upstream license files. Node.js and SQLite have their own licenses; official
Node container images include runtime licenses. There is no bundled GeoIP dataset.
